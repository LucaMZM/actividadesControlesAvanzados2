PROYECTO DAW

Controles avanzados con Git y GitHub

Proyecto realizado para practicar ramas, merges, resolución de conflictos, repositorios remotos y sincronización entre diferentes copias locales.

¿Qué se ha trabajado?

Durante la actividad se han creado diferentes ramas de desarrollo, se han realizado commits, merges y conflictos controlados para entender cómo funciona Git en proyectos colaborativos.

Objetivo

Aprender a utilizar Git y GitHub de forma práctica simulando situaciones reales de trabajo entre varios desarrolladores.
